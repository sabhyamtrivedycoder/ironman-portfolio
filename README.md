# The Invincible Sabhaym - Iron Man Comic 3D Portfolio

A bespoke comic-book themed 3D portfolio engineered from scratch for **Sabhaym Trivedi**, featuring a high-octane Iron Man / Stark Industries aesthetic with WebGL 3D Arc Reactor simulation, vintage comic fonts, halftone print textures, and an interactive armor vault.

## Architecture & Features

1. **Three.js 3D WebGL Arc Reactor**
   - High-precision 3D geometric assembly: outer dark titanium armor ring, 10 copper solenoid induction coils, counter-rotating inner laser-cut mechanical rings, and an emissive pulsating cyan plasma core.
   - 450+ additive blend energy particles swirling in a dynamic vortex.
   - Cursor-driven 3D parallax tilt and interactive repulsor overcharge mode with screen shake dynamics.

2. **Comic Book Typography & Art Direction**
   - Headings rendered in Google Fonts **Bangers** with 3D offset drop shadows (`4px 4px 0 #000, 8px 8px 0 #b91c1c, 12px 12px 0 #f59e0b`).
   - Dialogue presented in **Comic Neue** speech balloons with custom tail wedges.
   - Stark J.A.R.V.I.S. HUD telemetry styled in **Orbitron** and **Rajdhani**.
   - Ben-Day halftone dot pattern overlays and comic starburst action bursts.

3. **Stark Armory - Production Systems**
   - **Spark2Ship**: Autonomous prompt-to-live SaaS deployment platform (Python FastAPI, Next.js, Gemini 2.5 Flash, Stripe Billing).
   - **Sabhyam AI**: Digital twin runtime and multi-agent swarm orchestrator with Model Context Protocol (MCP) bridges.
   - **Gesture Spatial Engine**: Real-time biometric hand-tracking engine in 3D WebGL canvas via MediaPipe.

4. **Stark Armor Vault - High-Resolution Gallery**
   - Curated gallery of 12+ Iron Man armor specimens (Mark III, Mark XLIV Hulkbuster, supersonic flight mode, Silver Centurion, SDCC replicas, and 3D Arc Reactor renders).
   - Interactive category filtering (Cinematic Marks, Heavy Duty, Comic & Exhibitions) and full-screen technical lightbox viewer.

5. **Stark Intel Archives - 3D Bookshelf**
   - Exactly 3 books on a high-tech holographic pedestal:
     - *Steve Jobs* by Walter Isaacson
     - *Zero to One* by Peter Thiel
     - *Build, Don't Talk* by Raj Shamani
   - Click-to-inspect modal displaying key architectural directives and quotes.

6. **Procedural Web Audio Synthesizer**
   - Zero external audio files: synthesized on the fly via the Web Audio API with repulsor charge oscillators, white-noise blast bursts, and high-frequency HUD chirps.

7. **Identity & Strict Standards**
   - Engineer: Sabhaym Trivedi (14-year-old software engineer and founder from Jharkhand, India).
   - Contact: `sabhyamtrivedy@gmail.com`.
   - Zero emojis across all source files, comments, and documentation.
